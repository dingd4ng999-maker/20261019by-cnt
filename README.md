<h2 style="font-size:27px;line-height:1.5">四、Bybit 新用戶一定要做 KYC 嗎？</h2>

<p>目前 Bybit 個人 KYC 分為三個等級：</p>

<h3 style="font-size:23px;line-height:1.6">Standard</h3>

<p>主要包含：</p>

<ul>
<li>Identity Assessment 身分評估；</li>
<li>Proof of Identity（POI）身分證明。</li>
</ul>

<p>需要進一步提交：</p>

<p><strong>Proof of Address（POA）地址證明。</strong></p>

<p>通常需要先完成 Standard，才能繼續進行 Advanced。</p>

<h3 style="font-size:23px;line-height:1.6">Pro</h3>

<p>Pro 等級需要完成更進一步的：</p>

<p><strong>Enhanced Due Diligence（EDD）。</strong></p>

<p>可能涉及額外問卷、收入或相關支援文件。</p>

<p>不同地區還可能存在額外認證要求，因此最終應以自己帳戶的 Identity Verification 頁面為準。</p>

<h2 style="font-size:27px;line-height:1.5">八、為什麼 USDT 充值後不能直接交易？Funding Account 和 UTA 有什麼區別？</h2>

<p>Bybit 鏈上充值目前預設通常會進入：</p>

<p><strong>Funding Account</strong></p>

<p>Funding Account 主要用於：</p>

<ul>
<li>加密貨幣充值；</li>
<li>提幣；</li>
<li>部分法幣與資金管理功能。</li>
</ul>

<p>而：</p>

<p><strong>Unified Trading Account（UTA）</strong></p>

<p>主要用於：</p>

<ul>
<li>Spot；</li>
<li>Spot Margin；</li>
<li>Perpetual；</li>
<li>Futures；</li>
<li>Options 等支援的交易產品。</li>
</ul>

<p>所以如果 USDT 已經成功到帳，但交易頁面顯示可用餘額不足，先檢查資產是不是仍在 Funding Account。</p>

<p>需要劃轉時，可以進入：</p>

<p><strong>Assets → Transfer → From Funding Account → To Unified Trading Account → 選擇 USDT → 輸入金額 → Confirm</strong></p>

<p>這種操作只是 Bybit 帳戶內部資產劃轉，不是鏈上提幣，因此不要和向外部錢包發送 USDT 混淆。</p>

<p>Bybit 也支援用戶調整 Deposit Route，讓後續充值依照設定進入 Funding、UTA 或其他支援的帳戶。</p>
